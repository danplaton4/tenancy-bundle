    - `registerBundles()` returns `[new FrameworkBundle(), new TenancyBundle()]`
    - `registerContainerConfiguration(LoaderInterface $loader)` loads ONLY the minimal `framework` extension config (`secret`, `test`, `http_method_override: false`, `handle_all_throwables: true`, `cache.app: cache.adapter.array`) — IDENTICAL framework block to `TestKernel`.     - `getCacheDir()` / `getLogDir()` use `sys_get_temp_dir()` + `md5(static::class)` + environment, mirroring `TestKernel`.

Note: HostResolver is `private` in services.php; use a small compiler pass within this test file (e.g. `MakeZeroConfigServicesPublicPass`) that calls `setPublic(true)` on `HostResolver::class`, `HeaderResolver::class`, `QueryParamResolver::class`, `ConsoleResolver::class`, `TenantRunCommand::class` (when the `tenancy.command.run` id exists), and `TenantWorkerMiddleware::class` (when the `tenancy.messenger.worker_middleware` id exists — wrap in `hasDefinition` check because Messenger is optional).     3. `testConsoleApplicationVersionCommandExitsZero()` — boot the kernel, instantiate `Symfony\Bundle\FrameworkBundle\Console\Application` with the kernel, run it via `Symfony\Component\Console\Tester\ApplicationTester` against the `--version` invocation (or run `list` command), assert `$tester->getStatusCode() === 0`.
