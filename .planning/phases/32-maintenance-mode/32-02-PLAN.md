## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → kernel.request listener | Untrusted request (client IP, Accept header, _route, path) crosses here; allow-list decisions are made from it |
| CDN/proxy → 503 response | The 503 must not be cached at the edge or maintenance won't lift |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-32-04 | Spoofing | allow_ips bypass via forged X-Forwarded-For | mitigate | Use `$request->getClientIp()` which respects the app's trustedProxies config; document the proxy-trust requirement (ops docs, Phase 34). Bundle does not blindly trust XFF |
| T-32-05 | Denial of Service | landlord/public routes 503'd, locking operators out | mitigate | `!hasTenant()` early return (check 2) guarantees null-tenant (landlord/public/health) requests are never 503'd (MAINT-04) |
| T-32-06 | Denial of Service | CDN caches the 503 and keeps serving it after maintenance lifts | mitigate | Always set `Cache-Control: no-store, no-cache, must-revalidate` + `Pragma: no-cache` on the 503 (RESEARCH Pitfall 5) |
| T-32-07 | Denial of Service | custom Twig template itself throws → error page 500s (worst failure mode) | mitigate | Twig render wrapped in try/catch(\Throwable) with hardcoded-HTML fallback; hardcoded HTML is the default (D-01/D-02) |
| T-32-08 | Information Disclosure | one tenant's maintenance state affecting another tenant's request | mitigate | Listener reads only the request's already-resolved tenant from TenantContext; no static state; cross-tenant isolation test asserts B is unaffected |
| T-32-SC | Tampering | composer installs | accept | Zero new dependencies in this phase (RESEARCH § "No New Dependencies") |
