<objective>
Build the three operator commands: `tenancy:maintenance:enable <slug>`, `:disable <slug>`, and `:status`. Enable/disable are idempotent landlord-side writes that MUST invalidate the PSR cache key on toggle (the one genuine correctness question in this phase) and dispatch events only on a real transition. Status lists in-maintenance tenants via the cache-bypassing `findAll()`.

Purpose: MAINT-01/02/08/09. Correctly resolving the cache-coherence finding is the load-bearing part — without the `$cache->delete('tenancy.tenant.'.$slug)` after flush, maintenance state has up to a 5-minute propagation delay (CACHE_TTL = 300), which is unacceptable for an ops feature.
Output: 3 commands + 3 unit tests, green under `vendor/bin/phpunit --testsuite unit`.
</objective>
