- #[Shared] attribute: FQCN `Tenancy\Bundle\Attribute\Shared`; zero-param `#[\Attribute(\Attribute::TARGET_CLASS)] final class Shared {}`; mirrors `#[TenantAware]`.
- Write-protection exception: `Tenancy\Bundle\Exception\SharedEntityWriteInTenantContextException extends \LogicException`; static factory `::forEntity(string $entityClass, string $tenantSlug): self`; LogicException = no-retry under Messenger. Thrown by `SharedEntityWriteProtectionListener` onFlush for persist/update/delete of a #[Shared] entity in tenant context.
- Sync subscriber: `Tenancy\Bundle\Subscriber\SharedEntitySyncSubscriber`; onFlush buffers, postFlush applies/dispatches; landlord-EM-only via doctrine.event_listener `connection: landlord`; fan-out via TenantProviderInterface::findAll(); best-effort (per-tenant failure logged, never aborts landlord txn); covers insert/update/delete; short-circuits when driver === 'shared_db'.
- One-level cascade: SharedEntityCopier::applyRow copies getFieldNames() (scalars) ONLY; getAssociationNames() skipped → association to a non-#[Shared] entity is NULL on the tenant side. Fix: self-contained scalar entities, or mark associated entities #[Shared] too.
- Async mode: config `tenancy.shared.async: true` (default false); message `Tenancy\Bundle\Message\SharedEntityChangedMessage` carries (string entityClass, array identifier, string changeType in {insert,update,delete}) — never the full payload; handler `Tenancy\Bundle\MessageHandler\SharedEntityChangedMessageHandler` does the per-tenant loop (one message per changed entity, NOT per entity×tenant); handler re-fetches LATEST landlord state (tenants see latest, not dispatch-time — landmine); vanished row → tenant-side delete; user MUST configure framework.messenger.routing (not auto-routed; if unrouted, handles synchronously inline — landmine); compile-time guard `SharedAsyncContractPass` fails when async:true + Messenger absent.
- tenancy:shared:resync: name `tenancy:shared:resync`; class `Tenancy\Bundle\Command\SharedEntityResyncCommand`; options `--tenant` (VALUE_OPTIONAL, single slug; absent = all tenants), `--dry-run` (VALUE_NONE, classify without writing), `--force` (VALUE_NONE, skip confirmation). NO `--all` flag. shared_db → prints info + returns SUCCESS. Drift classes: would-insert / would-update / in-sync. Table cols: Tenant, Would-Insert, Would-Update, In-Sync, Status. Confirmation prompt 'Proceed with live resync?' default No; --force skips. Apply output `✓ <slug>` / `✗ <slug> (<message>)`; summary `Completed: N succeeded, M failed`. Exit SUCCESS on full success/no tenants, FAILURE if any tenant failed. Idempotent find-or-new (NOT ORM merge()).
- PHPStan rule IDs (VERIFIED): `tenancy.mutualExclusion` (MutualExclusionRule), `tenancy.sharedEntityLeak` (SharedEntityLeakRule), `tenancy.tenantIdDrift` (TenantIdDriftRule). Rule 2 gated by `checkSharedEntityLeaks` (default true; Rules 1 & 3 fire unconditionally). Rule 2 fires ONLY on concrete `Doctrine\ORM\EntityManager` caller — silent on `EntityManagerInterface` (conservative). Rule 3 accepted tenant_id types: string, ascii_string, guid, uuid (case-insensitive); fires on missing / nullable / non-string.
- Install paths: Path A `composer require --dev phpstan/extension-installer` (auto-reads composer.json#extra.phpstan.includes → extension.neon); Path B manual `includes: - vendor/danplaton4/tenancy-bundle/extension.neon`; Path C with phpstan/phpstan-doctrine → include `extension-doctrine.neon` INSTEAD OF extension.neon (NEVER both — double-registration fires every error twice). checkSharedEntityLeaks toggled under `parameters: tenancy: checkSharedEntityLeaks: false`.
