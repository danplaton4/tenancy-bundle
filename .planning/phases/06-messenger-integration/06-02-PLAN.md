    **Step 2: Update `src/TenancyBundle.php` `prependExtension()` method** — Add Messenger bus enrollment AFTER the existing Doctrine prepend logic. Add the `class_exists` guard at the TOP of the method so it short-circuits cleanly.

    Add the following block at the END of `prependExtension()`:

    ```php
    // Messenger middleware auto-enrollment — zero config (Decision D)
    if (class_exists(\Symfony\Component\Messenger\MessageBusInterface::class)) {
        $messengerConfigs = $builder->getExtensionConfig('framework');
        $buses = [];
        foreach ($messengerConfigs as $config) {
            foreach ($config['messenger']['buses'] ?? [] as $busName => $busConfig) {
                $buses[$busName] = true;
            }
        }

        // Cover the default bus when no explicit buses section exists
        if (empty($buses)) {
            $buses['messenger.bus.default'] = true;
        }

        $middlewareToInject = [
            ['id' => 'tenancy.messenger.sending_middleware'],
            ['id' => 'tenancy.messenger.worker_middleware'],
        ];

        foreach (array_keys($buses) as $busName) {
            $builder->prependExtensionConfig('framework', [
                'messenger' => [
                    'buses' => [
                        $busName => [
                            'middleware' => $middlewareToInject,
                        ],
                    ],
                ],
            ]);
        }
    }
    ```

    Important notes:
    - The `class_exists` guard uses `\Symfony\Component\Messenger\MessageBusInterface::class` — this is the canonical class to check for Messenger availability.
    - Do NOT add a `tenancy.messenger.enabled` config flag — per Decision D, this is always-on, zero config.
    - The `prependExtensionConfig` call prepends, so user config merges AFTER. This is correct — the bundle's middleware is added first, user can extend.
    - The `return` at the end of the Messenger block must NOT exit the entire method — the Doctrine prepend logic above must still execute. Use a separate `if` block, not early return.
