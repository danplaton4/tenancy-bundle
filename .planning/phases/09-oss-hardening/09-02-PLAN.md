- `bundles` configurator: registers `Tenancy\Bundle\TenancyBundle` in `config/bundles.php` for all environments
- `copy-from-recipe`: copies the recipe's `config/` directory contents into the app's `%CONFIG_DIR%/` (resolves to `config/`)
- `aliases`: allows `composer require tenancy` shorthand
- Version directory `1.0` = minimum package version the recipe supports (matches the branch-alias `1.0.x-dev`)
- Do NOT use `copy-from-package` (deprecated)
