The two bare marker attributes the rules detect (src/Attribute/Shared.php, src/Attribute/TenantAware.php):
  Both are `#[\Attribute(\Attribute::TARGET_CLASS)] final class` with NO constructor args.
  FQCNs: Tenancy\Bundle\Attribute\Shared, Tenancy\Bundle\Attribute\TenantAware
  Detection is presence-only: getAttributes(Shared::class) !== [].

The hierarchy-walk logic to extract (src/DependencyInjection/Compiler/SharedEntityMutualExclusionPass.php lines 81-90):
  private function hasAttributeInHierarchy(\ReflectionClass $rc, string $attribute): bool — loops
  `for ($current = $rc; false !== $current; $current = $current->getParentClass())` and returns true
  on the first `[] !== $current->getAttributes($attribute)`. PHP class attributes are NOT inherited,
  so a marker on a MappedSuperclass parent is only found by walking getParentClass().

PHPStan rule contract (resolvable now via existing vendor autoload — phpstan 2.1.50, verified):
  PHPStan\Node\InClassNode — virtual node; $node->getClassReflection() returns a populated ClassReflection.
  PHPStan\Rules\Rule — implement getNodeType(): string and processNode(Node, Scope): array (list<IdentifierRuleError>).
  PHPStan\Rules\RuleErrorBuilder::message(string)->identifier(string)->build() — the ONLY supported error path in 2.x.
  PHPStan\Testing\RuleTestCase<TRule> — base for tests; override getRule(): Rule and (static) getAdditionalConfigFiles(): array.

PSR-4 (composer.json — NO changes needed for autoload):
  Tenancy\Bundle\ -> src/   |   Tenancy\Bundle\Tests\ -> tests/
  phpunit.xml.dist <directory>tests/Unit</directory> already covers tests/Unit/PHPStan.
