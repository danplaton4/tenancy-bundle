<objective>
Deliver the D-04 / DEC-SHARE-03 mutual-exclusion guard: a container compiler pass that fails loud at boot when any entity carries both `#[Shared]` and `#[TenantAware]`. This is the boot-time half of the cross-tenant-leak prevention (Phase 28's PHPStan rule is the editor-time half — out of scope here).

**Open-question resolution (RESEARCH A1 / PATTERNS A1):** the pass enumerates candidate classes via the `tenancy.shared_entity` container tag — the exact `findTaggedServiceIds` pattern `FilesystemContractPass` uses with `tenancy.scoped`. This is compile-time robust (no kernel boot, no Doctrine-metadata scan needed), mirrors the established ContractPass convention, and is unit-testable identically to `FilesystemContractPassTest`. Tradeoff: users must register shared-entity service definitions with the `tenancy.shared_entity` tag for the guard to inspect them (documented in the Plan 25-04 docs note); a class that is never registered as a tagged service is not checked at compile time, but Phase 28's PHPStan rule will catch it at edit time. This tradeoff is acceptable because it keeps the pass deterministic and dependency-free, consistent with every other ContractPass in the bundle.

Purpose: prevent the data-leak bug class (an entity that is simultaneously a landlord master and tenant-scoped) at the earliest possible point.
Output: `src/DependencyInjection/Compiler/SharedEntityMutualExclusionPass.php`.
</objective>
