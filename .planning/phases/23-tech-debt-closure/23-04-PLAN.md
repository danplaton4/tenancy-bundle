    The section MUST:

    1. Print a section header line: `echo "==> Per-tenant mailer isolation (Mailpit assertion)"`.
    2. Define a local variable `MAILPIT_PORT="${PORT_MAILPIT_UI:-8025}"` to honor the env override that compose.yaml already supports.
    3. POST to `/_demo/send-test-mail` for each of two tenants (`acme`, `globex`) via:
       ```
       for slug in acme globex; do
           $CURL -X POST -H "Host: ${slug}.tenancy.localhost" "$BASE/_demo/send-test-mail" >/dev/null
       done
       ```
       Re-use the existing `$CURL` variable (already has retry/fail/timeout flags) — DO NOT define a separate curl invocation.
    4. Allow Mailpit a brief moment to receive both messages before the API query (the demo mailer may be async via Messenger; on a sync transport the messages land immediately, on async the worker has to drain). Insert a `sleep 1` between the POST loop and the Mailpit query. Do NOT use a long sleep; 1 second is sufficient for the demo's in-process worker (no transport hop) and acceptable CI cost.
    5. Query the Mailpit messages API:
       ```
       MESSAGES=$($CURL "http://127.0.0.1:${MAILPIT_PORT}/api/v1/messages")
       ```
    6. Assert distinct From: addresses via `jq -e`:
       ```
       echo "$MESSAGES" | jq -e '.messages[] | select(.From.Address == "noreply@acme.example")' >/dev/null \
           || { echo "FAIL: mailer isolation — acme From: address not found in Mailpit (TenantMessageDecorator regression?)"; exit 1; }
       echo "$MESSAGES" | jq -e '.messages[] | select(.From.Address == "noreply@globex.example")' >/dev/null \
           || { echo "FAIL: mailer isolation — globex From: address not found in Mailpit (TenantMessageDecorator regression?)"; exit 1; }
       ```
    7. Print success: `echo "    PASS: acme + globex From: addresses isolated correctly"`.

    Preserve `set -euo pipefail` semantics: every `$CURL` call inherits `--fail` (existing definition L8 includes `--fail`); jq's `-e` flag exits non-zero when the selector matches no objects (which `|| { … exit 1; }` then catches with a clearer message).

    Do NOT modify any line above the resolver-priority section. Do NOT remove any existing assertion. Do NOT introduce new env variables beyond `MAILPIT_PORT` (a local reuse of `PORT_MAILPIT_UI`).
