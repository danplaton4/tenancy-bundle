- `namespace Tenancy\Bundle\Bootstrapper;`
- `use Tenancy\Bundle\TenantInterface;`
- `interface TenantBootstrapperInterface`
- `public function boot(TenantInterface $tenant): void;`
- `public function clear(): void;`

Create `src/Bootstrapper/BootstrapperChain.php`:
- `namespace Tenancy\Bundle\Bootstrapper;`
- `use Tenancy\Bundle\TenantInterface;`
- `use Tenancy\Bundle\Event\TenantBootstrapped;`
- `use Symfony\Contracts\EventDispatcher\EventDispatcherInterface;`
- `final class BootstrapperChain`
- Constructor: `public function __construct(private readonly EventDispatcherInterface $eventDispatcher)`
- `/** @var TenantBootstrapperInterface[] */ private array $bootstrappers = [];`
- `public function addBootstrapper(TenantBootstrapperInterface $bootstrapper): void` — appends to `$this->bootstrappers`
- `public function boot(TenantInterface $tenant): void`:
  - `$fqcns = [];`
  - `foreach ($this->bootstrappers as $bootstrapper) { $bootstrapper->boot($tenant); $fqcns[] = $bootstrapper::class; }`
  - `$this->eventDispatcher->dispatch(new TenantBootstrapped($tenant, $fqcns));`
- `public function clear(): void`:
  - `foreach (array_reverse($this->bootstrappers) as $bootstrapper) { $bootstrapper->clear(); }`

Note: `TenantBootstrapped` event class does not exist yet (Plan 03). The BootstrapperChain file will reference it — this is intentional. The file will pass `php -l` syntax check but will fatal at runtime until Plan 03 creates the event class. This is acceptable because no code runs BootstrapperChain until Plan 05 wires everything together.

Update `config/services.php` to add `service('event_dispatcher')` as a constructor argument to `tenancy.bootstrapper_chain` service.

Create `tests/Unit/Bootstrapper/BootstrapperChainTest.php`:
- `namespace Tenancy\Bundle\Tests\Unit\Bootstrapper;`
- `use PHPUnit\Framework\TestCase;`
- Use a mock EventDispatcherInterface (the mock avoids runtime dependency on TenantBootstrapped)
- Test `testBootCallsAllBootstrappersInOrder`: create two mock TenantBootstrapperInterface, add them to chain, call boot(), assert both had boot() called with the tenant, verify order using an invocation tracker. Mock the EventDispatcher to accept any dispatch() call without type-checking the event argument.
- Test `testClearCallsBootstrappersInReverseOrder`: add bootstrapper A then B, call clear(), assert B's clear() is called before A's clear()

IMPORTANT: Do NOT include tests that reference TenantBootstrapped (testBootDispatchesTenantBootstrappedEvent, testBootWithNoBootstrappersStillDispatchesEvent). Those tests depend on the TenantBootstrapped class which is created in Plan 01-03. Those tests will be added in Plan 01-03 Task 3 after the event class exists.
