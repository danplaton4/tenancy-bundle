- `public function getName(): string` — returns `$this->name`
- `public function isActive(): bool` — returns `$this->isActive`

Setters (for mutation):
- `public function setDomain(?string $domain): self` — returns `$this` for fluency
- `public function setConnectionConfig(array $connectionConfig): self`
- `public function setName(string $name): self`
- `public function setIsActive(bool $isActive): self`

Timestamp getters:
- `public function getCreatedAt(): \DateTimeImmutable`
- `public function getUpdatedAt(): \DateTimeImmutable`
