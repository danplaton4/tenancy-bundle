<objective>
Extend the existing `tenancy:migrate` command with the operator-facing parallel surface: `--parallel`, `--concurrency=N`, `--dry-run`, and `--format=json`. The command delegates the multi-tenant parallel run to plan 01's `ParallelMigrationRunner` (built in wave 1), renders the human summary table or the aggregate JSON document from the returned `ParallelMigrationResult`, and wires the runner service into `src/TenancyBundle.php`. The existing sequential in-process loop stays byte-for-byte identical when `--parallel` is absent (Success Criterion 1).

Purpose: This is the command-layer half of Phase 31 — the part plan 01's `<objective>` explicitly defers to "plan 02". Plan 01 owns the subprocess pool; this plan owns flag wiring, the [1,32] clamp, the shared_db pre-branch guard, JSON-vs-table rendering, the exit-code rule, and the command/integration tests that prove the five ROADMAP Success Criteria.

Output: modified `src/Command/TenantMigrateCommand.php` + `src/TenancyBundle.php`, new `tests/Unit/Command/TenantMigrateCommandParallelTest.php`, new `tests/Integration/Command/TenantMigrateCommandParallelIntegrationTest.php`.

This plan CONSUMES plan 01's contract — it does NOT redefine the runner or its `ParallelMigrationResult` shape. Use the documented `run(array $tenants, int $concurrency, bool $dryRun, OutputInterface $output, bool $emitBlocks = true): ParallelMigrationResult` signature directly.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator CLI → command | Operator runs `tenancy:migrate --parallel --concurrency=N --format=json`; option values (`--concurrency`, `--format`) are operator-supplied strings parsed at the command layer. Trusted (developer at a shell), but malformed values must fail safe, not crash or spawn unbounded work. |
| command → ParallelMigrationRunner | The command forwards the parsed (clamped) concurrency, dry-run bool, and tenant list to the runner. The clamp is the command's responsibility; the runner trusts the already-clamped value. |
| command → tenant slug → child argv | Tenant slugs come from the bundle's own `TenantProviderInterface` (internal/trusted), flow through the runner into `'--tenant='.$slug` child argv. |
| shared_db driver → parallel path | Under shared_db a parallel run would corrupt the single shared migrations table; the command must refuse BEFORE the runner is reached. |
