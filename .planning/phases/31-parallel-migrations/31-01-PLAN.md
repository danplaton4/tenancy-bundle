<objective>
Build the `ParallelMigrationRunner` service: a bounded subprocess worker pool that spawns one `bin/console tenancy:migrate --tenant=<slug>` child per tenant, runs at most N concurrently via a non-blocking sliding-window poll loop, buffers each child's streamed output, and aggregates per-tenant results (status, migrations applied, duration, error).

Purpose: This is the novel subsystem of Phase 31 and the contract that plan 02's command modification delegates to. It encapsulates every parallel-migration pitfall mitigation (bounded concurrency, null-exit-as-failure, atomic output, streaming capture, SIGTERM forwarding) behind a single `run()` method with a `\Closure(list<string>): Process` test seam.
Output: `src/Command/Migration/ParallelMigrationRunner.php` (new service) + `tests/Unit/Command/Migration/ParallelMigrationRunnerTest.php` (new unit test).

This plan is interface-first: the runner's public `run()` signature and aggregate-result shape ARE the contract plan 02 consumes. Define them precisely here so plan 02 needs no exploration.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator CLI → runner | Operator invokes `tenancy:migrate --parallel`; tenant slugs come from the bundle's own `TenantProviderInterface` (internal/trusted), not from HTTP/untrusted input. |
| runner → spawned subprocess | The runner builds child argv and hands it to `Process`; the slug is interpolated into `'--tenant='.$slug`. |
| subprocess → tenant DB | Each child opens its own DBAL connection; N children = N connections against the DB's `max_connections`. |
| parent ← OS signals | Operator Ctrl-C / deploy SIGTERM can interrupt the parent mid-pool, risking orphaned children. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-31-01 | Tampering | child argv built from tenant slug | mitigate | Array-argv straight to `execve()` (`new Process([...])`) — NO shell, NO `Process::fromShellCommandline()`. Shell metacharacters in any slug token are inert (WR-04 lineage from TenantRunCommand). Verified by Task 1 grep gate + the argv-shape unit test. |
| T-31-02 | Denial of Service | N concurrent DBAL connections | mitigate | Bounded sliding-window pool capped at `$concurrency`; the value is clamped to [1,32] by plan 02's command before reaching the runner. The at-most-N unit test (Task 2) proves the pool never exceeds the cap (Pitfall 13 / ISOL-08). |
| T-31-03 | Denial of Service | orphaned/zombie subprocesses on interrupt | mitigate | SIGTERM/SIGINT handler (under `extension_loaded('pcntl')`) calls `$process->stop(0)` on all live children before `exit(1)` (Pitfall 18). On no-pcntl runtimes forwarding is documented-unavailable; `--concurrency=1` recommended. |
| T-31-04 | Repudiation | a killed child silently passing as success | mitigate | Null exit code recorded as FAILURE, never success (Pitfall 15 / D-07); the `getExitCode() ?? 0` anti-pattern is grep-gated out of the source and proven by the null-exit unit test. A falsely-green migration would hide an unmigrated tenant. |
| T-31-SC | Tampering | npm/pip/cargo/composer installs | accept | No new dependency is installed in this phase — `symfony/process` is already in `require` (RESEARCH: net-zero new prod deps; STACK reject list). No Package Legitimacy Gate applies. |
</threat_model>
