## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI input (--tenant=<slug>) | Untrusted slug crosses into findBySlug — existence validated |
| command → tenant EM (per tenant) | Cross-tenant write boundary: the wrong tenant's connection must never be written |
| confirm() gate → apply pass | A bulk cross-tenant write must not proceed without explicit consent |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-26-03-XTENANT | Tampering | Cross-tenant write to wrong EM | mitigate | BootstrapperChain::boot($tenant) wires the DBAL connection (close + reconnect via DatabaseSwitchBootstrapper) to the correct tenant before any applyRow; TenantContext enforces a single active tenant; finally clears both per tenant (RESEARCH Pitfall 2) |
| T-26-03-MASSWRITE | Tampering | Accidental mass-write to all tenants | mitigate | SymfonyStyle::confirm('Proceed?', false) default-No + --force for explicit unattended intent; -n without --force aborts cleanly with SUCCESS (D-04, Pitfall 6) |
| T-26-03-INPUT | Input Validation | --tenant=<slug> | mitigate | findBySlug() validates existence; TenantNotFoundException|TenantInactiveException caught → io->error + Command::FAILURE (V5 ASVS) |
| T-26-03-DRYRUN | Information Disclosure | --dry-run side effects | mitigate | Dry-run calls classifyRow only (read-only $tenantEm->find, no persist/flush) and returns before the prompt; never writes (D-03, Pitfall 3) |
| T-26-SC | Tampering | npm/pip/cargo installs | accept | No package installs — 26-RESEARCH.md Package Legitimacy Audit confirms zero new external packages |
