<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| copier → tenant EM flush | The copier writes #[Shared] rows into a tenant EM; the write-protection listener guards this boundary and must be bypassed ONLY while the copier-owned flag is set |
| #[Shared] enumeration → landlord metadata | Untrusted-class surface: only classes whose reflClass carries #[Shared] may be touched (proxy-safe via reflClass) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-26-02-FLAG | Tampering | syncInProgress flag permanence | mitigate | applyRow() sets the flag true immediately before flush and resets it false in a `finally` — the flag cannot leak permanently even if flush throws (RESEARCH Pitfall 1) |
| T-26-02-BYPASS | Elevation of Privilege | write-protection bypass scope | mitigate | The bypass flag lives on the copier and is only true inside applyRow()'s flush; user-originated tenant writes (flag false) still throw SharedEntityWriteInTenantContextException — bypass scoped to sync-only |
| T-26-02-PROXY | Spoofing | #[Shared] detection via runtime reflection | mitigate | isShared() + findSharedClasses() reflect ClassMetadata::$reflClass (the real mapped class), never `new \ReflectionClass($entity)` — proxy subclasses cannot evade or falsely trip the guard (WR-01) |
| T-26-02-REG | Tampering | Phase 25 regression from extraction | mitigate | SHARE-01 full integration suite is the explicit acceptance gate in Task 3 (SHARE-02-j) — observable behavior must remain identical |
