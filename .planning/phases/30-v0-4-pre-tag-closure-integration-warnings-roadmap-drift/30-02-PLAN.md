  <action>
    Edit the D-15 `bundles.php` awk block in `scripts/docs-lint.sh` (the `BUNDLES_VIOLATIONS=$(awk '...'` block). Add `FNR==1 { in_whitelist=0 }` as the FIRST rule inside the awk program — before the `/^## /` section-detection rule. This resets the whitelist state at the start of every file. `FNR` is the per-file record number (resets to 1 at each new file fed by `find docs/ -name '*.md'`); `NR` is global and never resets, so `FNR==1` is the correct idiom. Without this, a file ending inside a whitelisted H2 section leaves `in_whitelist=1` for the NEXT file, which then silently passes a non-whitelisted `bundles.php` reference (false negative). Change ONLY the awk program — leave the `find ... | grep -E 'bundles\.php'` pipeline, the surrounding `if [ -n "$BUNDLES_VIOLATIONS" ]` reporting block, and every other check in the script unchanged. Optionally update the explanatory comment block (lines 69-72) to note the per-file reset.
  </action>
