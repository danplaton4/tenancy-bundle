<objective>
Ship `AdapterDsnParser` — a pluggable DSN-string-to-FilesystemAdapter parser supporting three schemes out of the box: `local://`, `memory://`, `s3://`. The parser is the missing link between Plan 24-06's `TenantAwareFilesystemDecorator` (per_tenant_adapter mode) and the actual Flysystem adapter instantiation. Flysystem 3 does NOT ship a DSN parser of its own (RESEARCH.md §Don't Hand-Roll), so we build a minimal one scoped to v0.4 demand.

Per RESEARCH.md Open Question Q3 (recommendation adopted): unknown schemes raise `UnsupportedAdapterDsnSchemeException` (extends `\LogicException`) — same Messenger no-retry semantics as `MissingFilesystemConfigException`. Per Assumption A2 mitigation: the parser exposes a public registration API so future phases can plug in schemes without modifying core code.

Output: 1 new production file + 1 unit-test file flipped from incomplete to passing.
</objective>
