<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Application code → decorator | Application supplies path strings; decorator prepends tenant prefix and forwards to inner. Path-traversal protection is the application's concern (Pitfall 5). |
| TenantContext → decorator | Decorator reads tenant LIVE on every call. Stale state would be a cross-tenant leak. |
