- sf-toolbar-status-{red|yellow|green}   → toolbar status colors
- label-status-{error|warning|success}   → menu badge colors
- sf-toolbar-value                       → main badge value text
- sf-toolbar-info-piece                  → key/value rows in the toolbar tooltip
- metric / metrics                       → main panel metric tiles
- empty / empty-panel                    → "nothing to show" panel state

Critical structural rules (per RESEARCH.md and Symfony WebProfilerBundle conventions):
1. **`extends '@WebProfiler/Profiler/layout.html.twig'`** — required; WebProfilerBundle's templating pipeline relies on this base.
2. **Three blocks: `toolbar`, `menu`, `panel`** — block names are case-sensitive and exact; do not rename. `toolbar` renders the WDT badge; `menu` renders the sidebar entry; `panel` renders the full panel.
3. **`toolbar` block uses the `{% set icon %}{% endset %}` + `{% set text %}{% endset %}` + `include('@WebProfiler/Profiler/toolbar_item.html.twig', ...)` pattern** — this is the canonical Symfony WDT pattern; `toolbar_item.html.twig` handles the hover-tooltip CSS that turns `text` into a popover.
4. **Three states, three branches** — `{% if data.state == 'resolved' %}` / `{% elseif data.state == 'error' %}` / `{% else %}` — the order matters because the `else` covers the `'null'` case as the safe default.
5. **`collector.data.resolved_by|split('\\')|last`** — shows just the class name (e.g. `HostResolver` instead of `Tenancy\Bundle\Resolver\HostResolver`) in the cramped toolbar tooltip. Full FQCN is shown in the panel's `<code>` block.
6. **`bootstrappers|length` + `is empty` check** — handles the case where state is 'resolved' but bootstrappers is `[]` (a tenant resolved but bootstrapper chain didn't run, e.g. during unit-test scenarios) gracefully.
7. **`|default('-')` on every potentially-null scalar** — avoids "Variable does not exist" or empty output. Twig's `default()` filter handles both null and missing.
8. **No JavaScript, no inline `<style>` blocks, no external asset includes** — the WebProfilerBundle ships all CSS; we only use its provided class names.

Do NOT add a feature for displaying the captured exception's stack trace — D-03 forbids it and the data shape doesn't carry it.
Do NOT add per-bootstrapper status/timing — D-08 is locked at 8 keys; perf metrics are explicitly deferred (CONTEXT.md `<deferred>`).
