Create `tests/Integration/Profiler/TenantDataCollectorWdtTest.php` using the Write tool.

This is the most complex test in the phase. The simplest strategy: instead of driving a real HTTP request through a router (which requires registering controllers, routes, and a controller resolver — a lot of test infrastructure), DIRECTLY exercise the collector via the kernel's container.

**Strategy:**
1. Boot ProfilerTestKernel(test, true).
2. Resolve the container and grab: `tenancy.context` (TenantContext), `event_dispatcher`, `TenantProfilerStash::class`, `TenantDataCollector::class`.
3. For each state, manually:
   - state='resolved': set a tenant via TenantContext::setTenant, dispatch TenantResolved + TenantBootstrapped events via event_dispatcher
   - state='null': reset everything (no setup)
   - state='error': dispatch ExceptionEvent with a TenantNotFoundException
4. Call `$collector->collect(Request::create('/'), new Response())` directly.
5. Assert `$collector->getData()` matches expectations.
6. (Bonus — render through Twig) — resolve the `twig` service from the container; render the Twig template manually; assert substrings in the HTML output.

This approach avoids the HTTP-routing rabbit hole while still proving the END-TO-END pipeline (DI registration → event capture → collect() → data shape → Twig rendering).

Exact content:

```php
<?php

declare(strict_types=1);

namespace Tenancy\Bundle\Tests\Integration\Profiler;

use PHPUnit\Framework\MockObject\MockObject;
use PHPUnit\Framework\TestCase;
use Symfony\Component\EventDispatcher\EventDispatcherInterface;
use Symfony\Component\HttpFoundation\Request;
use Symfony\Component\HttpFoundation\Response;
use Symfony\Component\HttpKernel\Event\ExceptionEvent;
use Symfony\Component\HttpKernel\HttpKernelInterface;
use Tenancy\Bundle\Context\TenantContext;
use Tenancy\Bundle\Event\TenantBootstrapped;
use Tenancy\Bundle\Event\TenantResolved;
use Tenancy\Bundle\Exception\TenantNotFoundException;
use Tenancy\Bundle\Profiler\TenantDataCollector;
use Tenancy\Bundle\Profiler\TenantProfilerStash;
use Tenancy\Bundle\TenantInterface;
use Tenancy\Bundle\Tests\Integration\Profiler\Support\ProfilerTestKernel;

/**
 * End-to-end functional test for the Tenancy Profiler tab.
 *
 * Boots a kernel with FrameworkBundle + TwigBundle + WebProfilerBundle + TenancyBundle,
 * exercises the event → stash → collect pipeline for all 3 panel states, and asserts
 * both the 8-key data shape AND the rendered Twig output contain the expected substrings.
 *
 * Phase 19 — DX-02 success criteria 1, 2, 3 (resolved badge/panel, null state, error state).
 */
final class TenantDataCollectorWdtTest extends TestCase
{
    private static ProfilerTestKernel $kernel;

    public static function setUpBeforeClass(): void
    {
        self::$kernel = new ProfilerTestKernel('test', true);
        self::$kernel->boot();
    }

    public static function tearDownAfterClass(): void
    {
        self::$kernel->shutdown();
    }

    protected function setUp(): void
    {
        // Reset the stash between tests — long-running runtime semantics (kernel.reset).
        /** @var TenantProfilerStash $stash */
        $stash = self::$kernel->getContainer()->get(TenantProfilerStash::class);
        $stash->reset();

        /** @var TenantContext $tenantContext */
        $tenantContext = self::$kernel->getContainer()->get('tenancy.context');
        $tenantContext->clear();
    }

    public function testCollectorAndStashAreRegisteredInDebugKernel(): void
    {
        $container = self::$kernel->getContainer();
        self::assertTrue($container->has(TenantDataCollector::class));
        self::assertTrue($container->has(TenantProfilerStash::class));
        self::assertTrue($container->has('profiler'), 'Symfony Profiler service must be registered');
        self::assertTrue($container->has('twig'), 'Twig must be registered (required for template rendering)');
    }

    public function testResolvedTenantStateProducesCorrectDataAndRendersSlug(): void
    {
        $container = self::$kernel->getContainer();

        /** @var TenantContext $tenantContext */
        $tenantContext = $container->get('tenancy.context');
        /** @var EventDispatcherInterface $dispatcher */
        $dispatcher = $container->get('event_dispatcher');
        /** @var TenantDataCollector $collector */
        $collector = $container->get(TenantDataCollector::class);

        $tenant = $this->makeTenantMock('acme', 'Acme Corp');
        $tenantContext->setTenant($tenant);

        // Dispatch events so the stash captures resolved_by and bootstrappers.
        $dispatcher->dispatch(new TenantResolved($tenant, 'Tenancy\\Bundle\\Resolver\\HostResolver'));
        $dispatcher->dispatch(new TenantBootstrapped($tenant, [
            'Tenancy\\Bundle\\Bootstrapper\\Foo',
            'Tenancy\\Bundle\\Bootstrapper\\Bar',
        ]));

        $collector->collect(Request::create('/'), new Response());
        $data = $collector->getData();

        self::assertSame('resolved', $data['state']);
        self::assertSame('acme', $data['slug']);
        self::assertSame('Acme Corp', $data['tenant_label']);
        self::assertSame('Tenancy\\Bundle\\Resolver\\HostResolver', $data['resolved_by']);
        self::assertSame(['Tenancy\\Bundle\\Bootstrapper\\Foo', 'Tenancy\\Bundle\\Bootstrapper\\Bar'], $data['bootstrappers']);
        self::assertNull($data['error']);
        self::assertContains($data['driver'], ['database_per_tenant', 'shared_db', null]);
        self::assertIsString($data['connection_name']);
        self::assertStringNotContainsString(':', $data['connection_name']);
        self::assertStringNotContainsString('@', $data['connection_name']);

        // Render the panel through Twig and assert key substrings.
        $html = $this->renderPanel($collector);
        self::assertStringContainsString('acme', $html, 'Rendered panel must show the tenant slug');
        self::assertStringContainsString('Acme Corp', $html, 'Rendered panel must show the tenant label');
        self::assertStringContainsString('Tenancy\\Bundle\\Resolver\\HostResolver', $html, 'Rendered panel must show the resolver FQCN');
        self::assertStringContainsString('Tenancy\\Bundle\\Bootstrapper\\Foo', $html);
        self::assertStringContainsString('Tenancy\\Bundle\\Bootstrapper\\Bar', $html);
        self::assertStringContainsString('Bootstrappers (2)', $html);
    }

    public function testNullResolutionStateRendersEmDashAndNoTenantCopy(): void
    {
        $container = self::$kernel->getContainer();
        /** @var TenantDataCollector $collector */
        $collector = $container->get(TenantDataCollector::class);

        // No tenant set, no events dispatched — null state by default.
        $collector->collect(Request::create('/'), new Response());
        $data = $collector->getData();

        self::assertSame('null', $data['state']);
        self::assertNull($data['slug']);
        self::assertNull($data['tenant_label']);
        self::assertNull($data['resolved_by']);
        self::assertSame([], $data['bootstrappers']);
        self::assertNull($data['error']);

        $html = $this->renderPanel($collector);
        self::assertStringContainsString('—', $html, 'Rendered toolbar badge must contain em-dash for null state');
        self::assertStringContainsString('No tenant resolved', $html, 'Rendered panel must explain null state');
    }

    public function testErrorStateRendersWarningGlyphAndExceptionClass(): void
    {
        $container = self::$kernel->getContainer();
        /** @var EventDispatcherInterface $dispatcher */
        $dispatcher = $container->get('event_dispatcher');
        /** @var TenantDataCollector $collector */
        $collector = $container->get(TenantDataCollector::class);

        // Dispatch an ExceptionEvent with a tenancy exception so the stash captures it.
        $kernel = self::$kernel;
        $event = new ExceptionEvent(
            $kernel,
            Request::create('/'),
            HttpKernelInterface::MAIN_REQUEST,
            new TenantNotFoundException('tenant "ghost" not found')
        );
        $dispatcher->dispatch($event, 'kernel.exception');

        $collector->collect(Request::create('/'), new Response());
        $data = $collector->getData();

        self::assertSame('error', $data['state']);
        self::assertSame(TenantNotFoundException::class, $data['error']['class']);
        self::assertSame('tenant "ghost" not found', $data['error']['message']);

        $html = $this->renderPanel($collector);
        self::assertStringContainsString('⚠', $html, 'Rendered toolbar badge must contain warning glyph for error state');
        self::assertStringContainsString(TenantNotFoundException::class, $html, 'Rendered panel must show exception class FQCN');
        self::assertStringContainsString('tenant &quot;ghost&quot; not found', $html, 'Rendered panel must show exception message (HTML-escaped)');
    }

    private function makeTenantMock(string $slug, string $name): TenantInterface
    {
        /** @var TenantInterface&MockObject $tenant */
        $tenant = $this->createMock(TenantInterface::class);
        $tenant->method('getSlug')->willReturn($slug);
        $tenant->method('getName')->willReturn($name);

        return $tenant;
    }

    /**
     * Renders the Tenancy panel Twig template against the populated collector
     * and returns the resulting HTML string.
     */
    private function renderPanel(TenantDataCollector $collector): string
    {
        /** @var \Twig\Environment $twig */
        $twig = self::$kernel->getContainer()->get('twig');

        return $twig->render('@Tenancy/Collector/tenant.html.twig', [
            'collector' => $collector,
            'profiler_url' => '#',
            'token' => 'test-token',
        ]);
    }
}
```

Critical implementation notes:
1. **`setUpBeforeClass` / `tearDownAfterClass`** — boot kernel once per test class for speed; `setUp()` between tests resets stash + TenantContext for state isolation.
2. **`$dispatcher->dispatch($event, 'kernel.exception')`** — the explicit event name `'kernel.exception'` ensures `ExceptionEvent` triggers `TenantProfilerStash::onKernelException` (the `#[AsEventListener(event: ExceptionEvent::class, ...)]` attribute autoconfigures this binding, but passing the explicit name is defensive).
3. **`@Tenancy/Collector/tenant.html.twig` render via Twig env** — bypasses HTTP routing; renders the template directly. The template extends `@WebProfiler/Profiler/layout.html.twig`, which Twig resolves via the WebProfilerBundle's bundled templates (auto-discovered since WebProfilerBundle is registered).
4. **HTML escaping**: Twig auto-escapes `{{ }}` output. The exception message `'tenant "ghost" not found'` will render as `tenant &quot;ghost&quot; not found` in HTML — the test asserts the escaped form (T-19-08 mitigation verified).
5. **`profiler_url` and `token` are template input args** — the @WebProfiler/Profiler/layout.html.twig base template expects these context vars. Set to `'#'` and `'test-token'` (dummy values; we only test our template's block content, not the surrounding profiler chrome).
6. **If `setTenant()` doesn't exist on TenantContext**, the test must be adapted: e.g., bind the tenant via reflection or via the orchestrator's path. Verify the TenantContext API before writing the resolved-state test body. The bundle's Phase 1 convention is `setTenant()`; if it's something else, adapt.
7. **`em-dash` is the literal UTF-8 character `—`** (U+2014). Save the file as UTF-8 (the default for Write tool).
8. **`⚠` is the literal UTF-8 warning character** (U+26A0). Same UTF-8 encoding.
9. **No real HTTP route registered** — that would require controller_resolver setup. The Twig rendering happens directly from the test, proving the template+collector contract works.

Risk: if `'event_dispatcher'` service alias doesn't exist publicly (might be `event_dispatcher.public` or aliased differently in the test container), use `$container->get('event_dispatcher.public')` or `EventDispatcherInterface::class`. Verify by reading the existing `tests/Integration/AutoconfigurationTest.php` for how it accesses the dispatcher — that's the closest precedent.

Risk: if `'tenancy.context'` service alias isn't public, use `$container->get(TenantContext::class)`. Both should work; the existing `config/services.php` defines `tenancy.context` as an alias and makes the underlying service public.
