<objective>
Close the socket-leak loop: a dedicated `TenantContextClearedListener` subscribes to the existing `TenantContextCleared` event and calls `LruTransportCache::clear()` so all per-tenant SMTP sockets are stopped cleanly at request/message teardown. Ship the integration test that proves roadmap success criterion 6 ("After `TenantContextCleared` event, the per-tenant transport cache is cleared (verified by a long-running-worker simulation test that processes messages for 100 distinct tenants without unbounded socket growth)").

Purpose: Plan 03's `MailerBootstrapper::clear()` is one cleanup path — but `BootstrapperChain::clear()` runs in the request/worker teardown flow which may not always fire (e.g. in some Messenger middleware orderings, or if a non-fatal exception bypasses the bootstrapper chain). A dedicated event subscriber on `TenantContextCleared` is the canonical, redundant safety net — it fires regardless of which teardown path the kernel takes (HTTP via TenantContextOrchestrator, async via TenantWorkerMiddleware). Belt + suspenders on socket lifecycle.

Output: 1 new listener class + 1 services.php addition + 1 unit test + 1 integration test (the 100-tenant simulation that is the headline correctness proof for roadmap criterion 6).
</objective>

    ```php
    <?php
    declare(strict_types=1);

    namespace Tenancy\Bundle\Mailer;

    use Symfony\Component\EventDispatcher\EventSubscriberInterface;
    use Tenancy\Bundle\Event\TenantContextCleared;

    /**
     * Flushes the per-tenant SMTP transport cache when the tenant context is cleared.
     *
     * Subscribes to the bundle's TenantContextCleared event — dispatched by both
     * TenantContextOrchestrator (HTTP path: kernel.terminate / kernel.exception)
     * and TenantWorkerMiddleware (async path: after each handled message). This
     * guarantees the LruTransportCache is reset regardless of which teardown
     * path the kernel takes.
     *
     * Redundant with MailerBootstrapper::clear() — which also calls
     * LruTransportCache::clear(). Two paths to the same outcome is intentional:
     * the BootstrapperChain may not always be invoked (e.g. in some Messenger
     * middleware orderings), but TenantContextCleared is always dispatched.
     * Belt-and-suspenders on socket lifecycle (roadmap success criterion 6).
     */
    final class TenantContextClearedListener implements EventSubscriberInterface
    {
        public function __construct(private readonly LruTransportCache $cache) {}

        public function onContextCleared(TenantContextCleared $event): void
        {
            $this->cache->clear();
        }

        public static function getSubscribedEvents(): array
        {
            return [TenantContextCleared::class => 'onContextCleared'];
        }
    }
    ```

    **Test design (not testing real Messenger — testing the cache-clear loop that Messenger would drive):**

    ```php
    <?php
    declare(strict_types=1);
    namespace Tenancy\Bundle\Tests\Integration\Mailer;

    use PHPUnit\Framework\TestCase;
    use Symfony\Component\EventDispatcher\EventDispatcherInterface;
    use Tenancy\Bundle\Context\TenantContext;
    use Tenancy\Bundle\Event\TenantContextCleared;
    use Tenancy\Bundle\Mailer\LruTransportCache;
    use Tenancy\Bundle\Tests\Integration\Support\StubTenant;

    final class LongRunningWorkerSimulationTest extends TestCase
    {
        private static ?MailerTestKernel $kernel = null;

        public static function setUpBeforeClass(): void
        {
            if (!interface_exists(\Symfony\Component\Mailer\MailerInterface::class)) {
                self::markTestSkipped('symfony/mailer not installed');
            }
            // boot kernel; pattern from MessengerMiddlewareIntegrationTest
        }

        public static function tearDownAfterClass(): void { /* shutdown */ }

        protected function setUp(): void { /* clear context between tests */ }

        public function testCacheSizeRemainsBoundedAcross100Tenants(): void
        {
            $container = static::$kernel->getContainer();
            /** @var LruTransportCache $cache */ $cache = $container->get('tenancy.mailer.lru_cache');
            /** @var EventDispatcherInterface $dispatcher */ $dispatcher = $container->get('event_dispatcher');
            /** @var TenantContext $context */ $context = $container->get('tenancy.context');

            $maxSize = $cache->maxSize(); // 32 by default

            for ($i = 0; $i < 100; $i++) {
                $slug = "tenant_$i";
                $tenant = new StubTenant($slug);
                $tenant->setMailerDsn("smtp://u:p@host-$i:25");

                // Simulate one worker iteration
                $context->setTenant($tenant);
                // Manually drive the cache to simulate a send (the real send path
                // would call TenantAwareTransportsDecorator → cache->set)
                $spy = new SpyTransport($tenant->getMailerDsn());
                $cache->set($slug, $spy);

                // Assert cache never exceeds maxSize during the loop
                self::assertLessThanOrEqual($maxSize, $cache->size(), "After tenant $i, cache size exceeded maxSize ($maxSize)");

                // Simulate worker context teardown
                $dispatcher->dispatch(new TenantContextCleared());

                // After cleared event, cache is empty
                self::assertSame(0, $cache->size(), "After TenantContextCleared for tenant $i, cache should be empty");

                $context->clear();
            }
        }

        public function testCacheLruEvictionStaysBoundedWithoutContextClear(): void
        {
            // Scenario: 100 sends without intermediate clear — pure LRU eviction
            $container = static::$kernel->getContainer();
            /** @var LruTransportCache $cache */ $cache = $container->get('tenancy.mailer.lru_cache');
            $cache->clear(); // start from empty
            $maxSize = $cache->maxSize();

            for ($i = 0; $i < 100; $i++) {
                $cache->set("tenant_$i", new SpyTransport("smtp://h-$i"));
                self::assertLessThanOrEqual($maxSize, $cache->size());
            }

            // Final size = maxSize (LRU has been evicting)
            self::assertSame($maxSize, $cache->size());
            // Most recent slug is still present
            self::assertNotNull($cache->get("tenant_99"));
            // Earliest slugs evicted
            self::assertNull($cache->get("tenant_0"));
            self::assertGreaterThanOrEqual(100 - $maxSize, $cache->evictions(), 'LRU should have evicted at least (100 - maxSize) entries');
        }

        public function testListenerActuallyWiredIntoEventDispatcher(): void
        {
            // Sanity check: dispatching the event through the real container triggers the cache clear.
            // Without the listener wired in services.php (Plan 05 Task 1), this fails.
            $container = static::$kernel->getContainer();
            /** @var LruTransportCache $cache */ $cache = $container->get('tenancy.mailer.lru_cache');
            /** @var EventDispatcherInterface $dispatcher */ $dispatcher = $container->get('event_dispatcher');

            $cache->set('warmup', new SpyTransport('smtp://x'));
            self::assertSame(1, $cache->size());

            $dispatcher->dispatch(new TenantContextCleared());

            self::assertSame(0, $cache->size(), 'TenantContextClearedListener must have flushed the cache');
        }
    }
    ```
