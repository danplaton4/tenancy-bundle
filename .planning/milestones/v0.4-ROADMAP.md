# Milestone v0.4: Storage & Shared Entities

**Status:** ✅ SHIPPED 2026-06-19
**Phases:** 24–30 (7 phases: 24–29 feature phases + audit-driven Phase 30 pre-tag closure)
**Total Plans:** 34 plans across 7 phases
**Tag:** v0.4.0

## Overview

v0.4 was the **Storage & Shared Entities** milestone: make a real SaaS work end-to-end. v0.3 closed the install funnel; v0.4 closed the storage and data-sharing gaps that block real SaaS use cases.

**What v0.4 delivered:**
- Per-tenant Filesystem (Flysystem) bootstrapper — prefix mode + per-tenant-adapter mode, transparent to consumers
- Shared-entity sync model — landlord-side master record fans out a tenant-side read-only copy via Doctrine `postFlush`, with compile-time mutual exclusion and tenant-side write protection
- `tenancy:shared:resync` console command — idempotent bulk/initial sync with continue-on-failure and `--dry-run` diagnostics
- Async shared-entity fan-out via Symfony Messenger — opt-in `tenancy.shared.async: true`, scalar message, re-fetch-at-handle-time
- PHPStan extension — three rules (`tenancy.mutualExclusion` / `tenancy.sharedEntityLeak` / `tenancy.tenantIdDrift`) shipped via `phpstan/extension-installer` auto-load
- Docs refresh — new `shared-entities.md` + `phpstan-extension.md` + `filesystem-bootstrapper.md`, UPGRADE 0.3→0.4 (no breaking changes), `docs-lint.sh` shared-entity disambiguation check
- Audit-driven pre-tag closure (Phase 30) — extracted a single mockable `TenantEmSwitcher`, swapped two type-hints to `SharedEntityCopierInterface`, documented the resync-vs-per-event asymmetry, reconciled `docs/roadmap.md`, fixed a docs-lint awk state-leak

**Architectural decisions ratified (DEC-* IDs in `v0.4-REQUIREMENTS.md`):** DEC-FILE-01 prefix-mode default, DEC-FILE-02 optional config method via trait, DEC-SHARE-01 sync default, DEC-SHARE-02 one-level cascade, DEC-SHARE-03 compile-time mutual exclusion, DEC-PHPSTAN-01 extension-installer auto-load. Locked D-07 shared-entity vocabulary: "landlord-side master" + "tenant-side read-only copy".

**Explicit non-goals (carried from v0.3):** v1.0 tag (deferred until external adoption signals validate the public surface), Symfony Flex recipe (`tenancy:install` remains the onboarding path), cross-tenant queries via `#[Shared]` (the model is intentionally one-way landlord→tenant).

## Milestone Summary

**Decimal / inserted phases:**
- Phase 30: v0.4 pre-tag closure — inserted after Phase 29 to close audit-surfaced integration warnings + docs drift before tagging.

**Key Decisions:**
- DEC-FILE-01 — Filesystem adapter-strategy default `prefix` mode (lower-friction onboarding; per-tenant-adapter opt-in for S3-style separation)
- DEC-FILE-02 — Filesystem config method OPTIONAL via trait (no BC break; symmetric with BOOT-04 mailer pattern)
- DEC-SHARE-01 — Shared-entity sync default synchronous (predictable; async opt-in via `tenancy.shared.async`)
- DEC-SHARE-02 — Cascade depth one level only (avoids unbounded sync cost; explicit `#[Shared]` on each shared entity)
- DEC-SHARE-03 — `#[Shared]` + `#[TenantAware]` mutual exclusion enforced at compile time (prevents the data-leak bug class entirely)
- DEC-PHPSTAN-01 — Extension distributed via `phpstan/extension-installer` auto-load (zero-config, same pattern as phpstan-symfony/doctrine)
- D-07 — Locked shared-entity vocabulary: "landlord-side master" + "tenant-side read-only copy"
- Phase 30 — Single `TenantEmSwitcher` (interface + final class) owns `switchTo()`/`restore()`; resync intentionally keeps `setTenant()`+`bootstrapperChain->boot()` (documented W-03 asymmetry)
