### Cross-Phase WARNING (1/7)

**INT-01 — Twig hides mailer subsection on null/error states** (Phase 19 ↔ Phase 20)

- **File:** `src/Resources/views/Collector/tenant.html.twig` L108-149
- **Symptom:** Mailer block is nested inside the `state == 'resolved'` Twig branch, but `TenantDataCollector::collectMailerState()` populates the mailer scalar array on every request when `LruTransportCache` is wired (per Phase 20 D-08). The unit test `TenantDataCollectorMailerSectionTest::testMailerKeyPresentWhenNoTenantButCacheWired` asserts the mailer subsection "STILL renders with cache metrics + strategy" — but the template never reaches the block on null/error states.
- **Impact:** Operator can't see cache metrics on landlord, public, or health-check routes (the typical SaaS marketing pages). Cosmetic — not security-relevant; per-tenant mailer dispatch is unaffected.
- **Affected REQ-IDs:** DX-02, BOOT-04
- **Recommendation:** v0.3.3 polish OR defer to v0.4 with an explicit note. Either move the `{% if collector.data.mailer is defined %}` block out of the resolved branch, or correct the unit-test comment to state "data is present but not rendered".
